怎么用
1. 首次使用：设备开热点 NES-XXXX，手机连上，密码默认 nes12345。
2. 打开 http://192.168.4.1/，在「网络」里填家里 2.4GHz Wi-Fi，保存后设备重启并加入局域网。
3. 之后用屏幕上显示的 IP 直接打开本页，上传 ROM、启动游戏。
4. 设备屏幕用 BOOT 键或手柄方向键选择，A / 长按 BOOT 开始；游戏中长按 BOOT 或 Select+Start 退出。
5. ROM 文件名建议用英文/数字：设备菜单只带 ASCII 字库，中文名会显示成 ?。
